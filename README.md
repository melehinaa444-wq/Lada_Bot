# Автоответчик Лады

Python 3.10+, без сторонних библиотек. После сообщения владельца пауза
в конкретном чате на 24 часа. Команды: /on, /off, /status.

## Railway

1. Загрузите содержимое этой папки в корень репозитория GitHub.
2. В Railway выберите этот репозиторий.
3. В Variables добавьте BOT_TOKEN — новый токен из BotFather.
   Опубликованный в переписке токен нужно отозвать через /revoke.
4. Подключите постоянный Volume в /data для настроек и пауз.
   Для Docker-пользователя 10001 должен быть разрешён доступ на запись.
5. Оставьте одну копию сервиса (одну реплику), без режима сна.
6. Остановите старую Windows-копию до запуска на Railway.
7. Проверьте журнал запуска, ответ с другого аккаунта и паузу после ответа Лады.

Публичный домен не требуется: бот использует getUpdates.
Бот должен быть подключён к аккаунту Лады с правом отвечать.
При смене токена обновите BOT_TOKEN в Railway и перезапустите сервис.
Не добавляйте токены, файлы .env и базы данных в репозиторий.
Без постоянного тома паузы и настройки могут потеряться при перезапуске.
